# Quick Reference

## Advantage and disadvantage

| Source | Effect |
| --- | --- |
| Your choice when rolling | Enter any level; + for advantage, − for disadvantage |
| Target has Half / Full Cover | 1× / 2× disadvantage |
| Target is Surrounded, Prone (melee) | 1× advantage |
| Target is Cornered | 1× advantage |
| Target is Shadowed | 1× disadvantage |
| You have Height | 1× advantage |
| You are inside Suppressing Fire | 1× disadvantage |
| You are Prone | 1× disadvantage on your attacks |

Advantage on a check with several dice means rolling extra dice and keeping the best. Disadvantage means
that many checks fail automatically.

## Chat card buttons

| Button | Who clicks it | What it does |
| --- | --- | --- |
| **Roll Save** | The target's player (token selected) | Rolls the Trait Check(s) the card forces |
| **Roll Save to Negate** | The target's player | Resists an on-hit condition ("Finesse check negates") |
| **Apply / No DR / Undo** | GM | Applies damage with or without DR, or reverts it |
| **→ level / Undo** | GM | Applies or reverts condition levels |
| Reaction buttons | The named character's owner | Uses an after-the-roll reaction |
| **Mind Map: re-roll** | The Oracle | Re-rolls the Insane table for a Prescient point |

## Glossary

- **AP:** Action Points, spent on actions and refilled each turn.
- **Limbs:** arm, legs, body, and mind. Reusing an exhausted limb costs +1 AP.
- **Boost:** armed ahead of time; changes your next matching action.
- **Focus:** lasts while you maintain it, by using its action again each turn.
- **Enduring:** a condition that doesn't drop at the end of your turn.
- **Check DC:** the number others roll against when you force a Trait Check.
- **Zone:** a placed area (a Foundry Region) that affects creatures inside it.
